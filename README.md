# Finley O'Mahony — Student Portfolio

A responsive student portfolio website for Finley O'Mahony at the University of California, Riverside.

## What's included
- `index.html` — page content and navigation
- `style.css` — layout, typography, colors, and mobile styling
- `img/website.svg` — site icon
- `img/profile-placeholder.svg` — optional profile illustration placeholder
- `img/portfolio1.svg` through `img/portfolio4.svg` — project artwork

## Preview locally
Open `index.html` in a web browser. The page uses Google Fonts when an internet connection is available and falls back to system fonts if it is not.

## Publish with GitHub Pages
1. Put the files in a repository named `fomah001-bapple.github.io` for a user site.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. Give GitHub a moment to publish the page.

The intended user-site address is `https://fomah001-bapple.github.io/`. The repository name must match the username-based format exactly, without a trailing period.
